## 👋 Intro

<b>Pro DoubleClick</b> is a lightweight Chrome extension (MV3 compliant), provides an incredibly convenient way to quickly open multiple webpages without having to manually `ctrl + click` or `ctrl + shift + click` link. Improve your workflow; just Double Click to open links in a new tab (front or background). 

Designed with minimalist UI yet packed with customization. Save time, maximize your productivity and experience fluid browsing with Pro DoubleClick!

## 🎮 How to use

<div align="center">
<img src="assets\UIUX.png" width="350" />
</div>
<p></p>

<b>1. Title – Pro DoubleClick -</b> Click the title to visit the Microsoft Edge Add‑ons store for review or share the extension.

<b> 2. Current Site Status -</b>
Displays the active setting for current site. `Default`, `Override`, `Inactive`

<b>3. Current Site Configuration -</b>
Configure whether links on the Current Site open in a **Front Tab** or **Back Tab**. Settings are auto‑saved instantly for future visits.

<b>4. Default Configuration  -</b>
Set the global preference for all websites: configure whether links open in a **Front Tab** or **Back Tab** by default. Settings are auto‑saved instantly for future visits.

<b>5. Bottom Control Options:</b>
<ul>
<b>Option:</b>
Opens a separate panel to manage site-specific preferences.
</ul>
<ul>
    <b>Remove:</b>
Deletes custom settings for the current site, including link behavior or block rules.  
</ul>
<ul>
    <b>Reset:</b>
Restores extension to factory defaults.
</ul>
<ul>
    <b>Block:</b>
Blacklists the current site to prevent the extension from running or interfering with its links.
</ul>

## 🔒 Privacy & Security

> [!CAUTION]
> Your browser may display pop up warning after installing Pro DoubleClick, it is just a standard precaution message; you can ignore that.

> [!IMPORTANT]
> Pro DoubleClick never collects user data, browsing history, or click behavior. Your activity stays entirely yours. As a pure utility extension, its sole purpose is to streamline user productivity.

> [!NOTE]
> Pro DoubleClick requires below mentioned permissions:
>
>`tabs` essential for opening links in a new tab (front or background)
>
>`activeTab` gives the extension temporary access to the currently active tab
>
>`storage` used to save user site‑specific preferences and settings locally
